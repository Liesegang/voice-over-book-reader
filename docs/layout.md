# EPUBの単頁、見開きと固定レイアウト

## 0.3の本文表示

0.3では、書籍の原文XHTML、CSS、SVGとローカルリソースを同梱Chromiumで描画します。
本棚、メニュー、設定はネイティブRustです。
固定ページは著者のviewportを使い、リフロー文書は現在の表示領域と文字設定でページ分割します。
原文位置とページ数の対応、未検証の範囲は[EPUB対応状況](epub-support.md)を参照してください。

## 0.2系のネイティブ組版

以下は旧ネイティブ描画系の表示規則を記録したものです。
0.3のChromium実装で、以下のすべての挙動を検証したという意味ではありません。

表示方法を「自動」にすると、EPUBの表示指定を読み取ります。
書籍全体の指定を基本に、各spine項目の指定を適用します。
表紙や中央配置のページを単独で表示し、左右の指定があるページは対応する側へ置きます。
戻る操作でも、閲覧履歴ではなく書籍内の並びから組を決めます。

| EPUBの指定 | 扱い |
| --- | --- |
| `rendition:layout` / `rendition:layout-*` | 固定レイアウトか、文字を画面に合わせて組み直すページかを判定 |
| `rendition:spread` / `rendition:spread-*` | 単頁、横長時と縦長時の見開き、常時見開きの指定を読む |
| `page-spread-left/right` と `rendition:page-spread-left/right` | 左右の物理的な配置先を読む |
| `rendition:page-spread-center` | 中央の単頁として表示 |
| XHTMLの`meta name="viewport"` | 固定ページの幅と高さを読む |
| SVGの`viewBox` | SVGページの座標と縦横比を保つ |

単頁指定や中央配置のページは、横長の画像でも一枚の構成を保ちます。
見開きの左右は本の進行方向に合わせ、単独表示の指定があるページは、隣のページと組み合わせません。

指定がない場合、文字は通常一面、画像ページは画面と画像の縦横比をもとに表示します。
「文字の見開き」は別設定です。
表示方法を「単頁」にすると一枚ずつ読めます。
「見開き」を選んだ場合も、EPUBが単独表示を指定するページはその指定を守ります。

固定ページは書籍の座標と縦横比を保って画面内に収めます。
リフロー用の文字サイズやページ余白を、固定ページ内の座標へ加えません。
文字の本にある小さな外字画像は固定ページとみなさず、本文の指定サイズで描画します。

進捗スライダーには、章数の比率ではなく、その設定と画面サイズで組版したページ数を使います。
文字の章はバックグラウンドで順に計算し、固定画像ページは一枚ずつ数えます。
計算結果は設定と画面サイズごとに保存します。
計算中の移動要求は、結果が出てから対象ページへ適用します。
ここでのページ数は表示上のもので、紙の版やEPUBのpage-listと同じ番号とは限りません。

解釈するメタデータと寸法の基準は[W3C EPUB 3.3](https://www.w3.org/TR/epub-33/)です。
本文の描画は、ブラウザーのようにすべてのCSSやスクリプトを扱うものではありません。
複雑な固定レイアウトには引き続き制約があります。

単色の外字画像と数式の色を配色に合わせる設定は、既定でオンです。
挿絵や写真は色変換の対象から除きます。
